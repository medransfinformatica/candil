# candil
CANDIL OS es un ecosistema local y web con estética criolla que unifica una suite completa de programas creativos de código abierto. Te permite acceder desde el navegador a alternativas a Photoshop, Illustrator, Premiere, Lightroom, After Effects, InDesign y Acrobat, ejecutadas de forma nativa en Rust/Wasm, sin suscripciones ni dependencias.
